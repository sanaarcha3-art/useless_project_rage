# RageDesk Audio Assets

Place audio files here before running:

| Filename | Description |
|---|---|
| `hammer_impact.mp3` | Heavy thud impact sound |
| `glass_crack.mp3` | Glass/surface cracking |

For Phase 3+, also add:
- `drill.mp3` — looping drill sound
- `axe_slash.mp3` — sharp axe swing
- `paintball_hit.mp3` — wet splat
- `explosion.mp3` — big boom
- `fire_loop.mp3` — crackling fire (loop)
- `blackhole_whoosh.mp3` — deep gravitational pull

Free sources: freesound.org, zapsplat.com, mixkit.co
The app will log a warning and silently skip any missing audio files.
